# ODE_practices
В папке Homework будут размещаться листки с домашними заданиями. Задачи с пометкой "Ф" взяты из сборника Филиппова "Сборник задач по дифференциальным уравнениям".


Для лучшей визуализации и понимания различных аспектов ДУ, реализованы матлеты (интерактивные виджеты) по аналогии с mathlets от MIT. 

Открываются в браузере через Google Colab — устанавливать ничего не нужно, достаточно аккаунта Google. В Colab: «Среда выполнения» → «Выполнить всё» (Ctrl+F9), затем крутить ползунки под графиком. Первый запуск занимает 10–20 секунд — Colab поднимает машину.

Изменения, которые вы вносите в Colab, в этот репозиторий не попадают: Colab работает с копией. Сломать ничего нельзя, можно смело экспериментировать.
